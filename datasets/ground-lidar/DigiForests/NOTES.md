# DigiForests notes

- **LiDAR sensor model:** The official page says “backpack-carried automotive LiDAR sensors” and a UAV LiDAR system; a model name is **NOT STATED IN SOURCES**. [Official page](https://www.ipb.uni-bonn.de/data/digiforest-dataset/)
- **IMU included:** **NOT STATED IN SOURCES**. The sources describe LiDAR point clouds and poses, but do not confirm a distributed raw IMU stream. [Official page](https://www.ipb.uni-bonn.de/data/digiforest-dataset/) [GitHub README](https://github.com/PRBonn/digiforests/blob/main/README.md)
- **Continuous walking or driving sequences:** The dataset has multiple recording sessions and repeated plots in March 2023, October 2023, and July 2024, but whether each is a continuous walking/driving sequence and its duration are **NOT STATED IN SOURCES**. [Official page](https://www.ipb.uni-bonn.de/data/digiforest-dataset/)
- **Point-cloud format:** The development-kit documentation specifies point-cloud files and binary labels; exact point-cloud extension is **NOT STATED IN SOURCES** there. [Data-loader README](https://github.com/PRBonn/digiforests/blob/main/scripts/data/README.md)
- **Labels:** Tree, shrub, and ground semantic labels; tree instances; and fine-grained tree stem/crown semantics are provided. DBH is an estimation task and a field DBH ground-truth field is **NOT STATED IN SOURCES**. [GitHub README](https://github.com/PRBonn/digiforests/blob/main/README.md) [Official page](https://www.ipb.uni-bonn.de/data/digiforest-dataset/)
- **Region and forest type:** Forest near Stein am Rhein, Switzerland; plot tree types are shown on the official page, but a single named forest type is **NOT STATED IN SOURCES**. [Official page](https://www.ipb.uni-bonn.de/data/digiforest-dataset/)
