# LiDAR-Forest (Purdue) notes

- **LiDAR sensor model:** The simulation prototype is Velodyne VLP-16. [Paper](https://arxiv.org/html/2402.04546v2)
- **IMU included:** **NOT STATED IN SOURCES**. The paper simulates a person walking with a backpack LiDAR, but the accessed paper and project page do not document an IMU output stream. [Paper](https://arxiv.org/html/2402.04546v2) [Official project page](https://lidar-simulate.github.io/LiDAR_simulate/)
- **Continuous walking or driving sequences:** Walking movement and a configurable scanning path are simulated; sequence duration/length is controlled by total frames and is **NOT STATED IN SOURCES** as a fixed dataset duration. [Paper](https://arxiv.org/html/2402.04546v2)
- **Point-cloud format:** Relative and absolute records contain x, y, z coordinates plus leaf/wood, semantic, and instance labels; a file extension is **NOT STATED IN SOURCES**. [Paper](https://arxiv.org/html/2402.04546v2)
- **Labels:** Leaf/wood labels, semantic labels such as ground, tree, and stone, and instance labels are described. Shrub, stem, and DBH ground-truth labels are **NOT STATED IN SOURCES**; the project page says the tool can evaluate DBH estimation. [Paper](https://arxiv.org/html/2402.04546v2) [Official project page](https://lidar-simulate.github.io/LiDAR_simulate/)
- **Region and forest type:** Unreal Engine forest scenes with customizable tree species and scene generation; a real-world region or forest type is **NOT STATED IN SOURCES**. [Official project page](https://lidar-simulate.github.io/LiDAR_simulate/)
- **Licence:** **NOT STATED IN SOURCES**. [Official project page](https://lidar-simulate.github.io/LiDAR_simulate/) [Paper](https://arxiv.org/html/2402.04546v2)
- **Download size:** **NOT STATED IN SOURCES**. [Official project page](https://lidar-simulate.github.io/LiDAR_simulate/) [Paper](https://arxiv.org/html/2402.04546v2)

Paper: [LiDAR-Forest arXiv paper](https://arxiv.org/abs/2402.04546). No separate official GitHub README was identified; the project page and paper are the official documentation found.
