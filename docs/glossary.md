# Glossary

- **Point cloud:** A collection of 3D points. Each point may also have intensity, time, or a label.
- **LiDAR:** A sensor that measures distance by sending laser pulses and timing their return.
- **SLAM:** Simultaneous Localization and Mapping: estimating the sensor pose while building a map.
- **IMU:** An inertial measurement unit containing accelerometers and gyroscopes that measure motion and rotation.
- **RANSAC:** A method that fits a model while ignoring many outlier measurements.
- **DBH:** Diameter at breast height, conventionally measured around 1.3 m above the ground.
- **Ladder fuels:** Low vegetation and branches that can carry a fire from the ground into tree crowns.
- **Canopy:** The upper layer formed by tree crowns and leaves.
- **Understory:** Vegetation below the main canopy, including shrubs and young trees.
- **NDVI:** A vegetation index using near-infrared and red reflectance: `(NIR - red) / (NIR + red)`.
- **NDWI:** A water-related index commonly using green and near-infrared reflectance: `(green - NIR) / (green + NIR)`.
- **U-Net:** An encoder-decoder neural network commonly used to predict a class for each image pixel.
- **GEDI:** NASA's spaceborne lidar mission for measuring forest structure and canopy height.
